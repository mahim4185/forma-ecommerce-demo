FORMA — PREMIUM E-COMMERCE STOREFRONT DEMO
Created as a portfolio concept by Mahim Digital Studio.

IMPORTANT:
- FORMA is a fictional demo brand, not a real client or shop.
- Product names, prices, and descriptions are sample content. Replace them before client delivery.
- Product images load from Unsplash and need an internet connection.
- Add to bag and cart subtotal work in the browser.
- Checkout is a demo alert only. Newsletter form does not store email addresses.
- This is a static front-end only. It has no server, inventory, order database, customer accounts, or real payment gateway.
- Never collect real customer payments until a secure backend and trusted payment provider are configured.

PUBLISH WITH GITHUB PAGES:
1. Extract this ZIP on your phone/computer.
2. Create a new PUBLIC GitHub repository named forma-ecommerce-demo.
3. Upload index.html to the repository root (not the ZIP file).
4. Open Settings > Pages.
5. Select Deploy from a branch, choose main and /(root), then Save.
6. Wait for GitHub Pages to publish.
